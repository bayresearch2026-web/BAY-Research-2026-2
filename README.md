# BAY 리서치팀 뉴스트래킹 — 노션 연결 배포 안내

노션 표에 뉴스를 한 줄씩 쌓으면 이 홈페이지에 자동으로 표시됩니다.
코드는 건드릴 필요 없고, 아래 순서대로 클릭·복붙만 하면 됩니다.

## 폴더 구성
- `index.html` — 홈페이지(디자인/화면). 발행일로 주차를 자동 계산합니다.
- `api/posts.js` — **목록용.** 제목·작성자·날짜·요약·주제·썸네일만 가져옵니다 (본문은 안 읽음)
- `api/post.js` — **기사 1건용.** 독자가 글을 눌렀을 때 그 글의 본문만 가져옵니다
- `api/_notion.js` — 위 두 함수가 함께 쓰는 부품 모음 (직접 열리는 주소가 아닙니다)
- `package.json` — 배포 설정(안 건드림)

> **속도 안내(2026.07 개선)** — 예전에는 목록을 그리려고 글 전체(70여 건)의 노션 본문을
> 매번 읽어와서 첫 화면이 뜨는 데 20~30초가 걸렸습니다. 지금은 목록과 본문을 나눠서
> 첫 화면은 1~2초, 기사 본문은 눌렀을 때 그 글 하나만(0.5~1초) 읽어옵니다.
> 카드에 마우스를 올리면 미리 받아두기 때문에 실제로는 대부분 즉시 열립니다.
> 한 번 읽은 글은 기억해 두므로 다시 열 때는 기다림이 없습니다.

## 1. 노션 데이터베이스 구조 (중요)

**뉴스 1건 = 표의 한 줄**이 되도록, 뉴스를 **하나의 데이터베이스**에 모아 쌓습니다.
(주마다 새 페이지/표를 따로 만들면 표 ID가 매주 달라져 연결이 깨집니다.
 대신 이 표 하나를 노션에서 '주차별 뷰'로 묶어 보면 지금처럼 주간정리로 보입니다.)

아래 속성(열)을 두세요. **이름은 영어 그대로** 두는 게 안전합니다(코드가 이 이름으로 읽음).

| 속성 이름 | 타입 | 비고 |
|---|---|---|
| Title | 제목(Title) | 이미 있음 |
| Author | 사람(Person) 또는 선택 | **뉴스 행에 추가** (지금은 주간 페이지에만 있음) |
| Date of Issue | 날짜(Date) | 이미 있음. 이 날짜로 주차 자동 계산 |
| Content Summary | 텍스트 | 이미 있음 → 요약 |
| Insight | 텍스트 | 인사이트 (아래 설명) |
| Source | URL | 이미 있음 |
| Tag | 다중 선택(Multi-select) | 선택사항 (RWA·규제동향·프로젝트…) |
| Topic | 선택(Select) 또는 다중 선택 | 주제 분류. **홈 화면의 주제별 탭**과 주제별 페이지에 사용 |
| Pick | **체크박스(Checkbox)** | **새로 추가.** 체크한 글이 홈의 `Editor's Picks`에 노출됩니다 (최대 6개) |
| Status | 상태(Status) | 값이 `홈페이지 게시`인 뉴스만 사이트에 게시. `미완`·미선택은 숨김 |
| Likes | 숫자(Number) | 좋아요 수 저장용 (선택) |
| Views | 숫자(Number) | **조회수 저장용.** 이 열을 만들면 사이트에 "읽음 N"이 표시됩니다 |

**홈(대시보드) 화면 구성:** `홈` 탭은 세 덩어리로 되어 있습니다.
1. **큰 기사 1건 + 오른쪽 최신 4건** — 큰 기사는 *이미지가 있는 가장 최근 글*이 자동 선택됩니다(2:1 비율).
   대표 이미지를 넣은 글이 자동으로 맨 앞에 걸린다고 보시면 됩니다.
2. **Editor's Picks 6건** — `Pick` 체크박스를 켠 글. 체크한 글이 하나도 없으면 조회수·좋아요가 많은 순으로 자동 표시됩니다.
3. **주제별 탭** — `Topic` 값이 탭으로 나오고, 탭을 누르면 그 주제의 최신 글 6개(3개씩 두 줄)가 아래에 표시됩니다.

**주제별 화면:** 상단 메뉴의 `주제별`도 홈과 똑같은 탭 대시보드로 되어 있습니다(탭마다 최신 9건).
탭 오른쪽 `더보기 →` 를 누르면 그 주제의 전체 목록으로 넘어가고, 그 화면 위에도 같은 탭이 있어
뒤로 가지 않고 바로 다른 주제로 이동할 수 있습니다. 아직 분류 안 한 글은 `미분류` 탭에 모입니다.

**이미지:** 뉴스 페이지 본문에 이미지를 넣으면 **첫 번째 이미지**가 기사 상단 배너 겸
목록 카드 썸네일로 자동 사용됩니다(본문에서는 중복 표시되지 않음). 두 번째부터는 본문 안에 그대로 나옵니다.
본문에 이미지가 없으면 페이지 표지(cover) → `Image`/`썸네일` 파일 속성 순으로 찾습니다.

**조회수:** `Views` 숫자 열만 만들면 됩니다. 같은 브라우저에서 같은 글은 **하루 1회**만 집계돼
새로고침으로 부풀지 않습니다. 열이 없으면 조회수만 표시되지 않고 나머지는 정상 동작합니다.
확인이 필요하면 `배포주소/api/view?debug=1` 을 열어보세요.

**인사이트는 두 가지 방식 다 지원합니다:**
- `Insight` 속성 칸에 텍스트로 적으면 → 그대로 사용
- 비워두면 → 그 뉴스 페이지 **본문**(소제목+문단)을 읽어와 인사이트로 사용
→ 지금처럼 본문에 정리해 오셔도 그대로 나옵니다.

**주간 페이지를 예쁘게 유지하는 법 (Linked view):**
데이터는 마스터 DB 하나에 두되, 각 주간 페이지에는 그 DB의 **연결된 보기(linked view)**를 넣고
해당 주로 필터하면 됩니다. 데이터는 한 곳(=한 ID)에 모이고, 보기만 주별로 예쁘게 나뉩니다.
- 주간 페이지에서 `/linked` 입력 → "Linked view of database" → 마스터 DB 선택
- 그 보기에 필터: Date of Issue가 그 주 범위(또는 Week 속성 = 해당 주)
- 연결된 보기에서 행을 추가하면 마스터 DB에 자동으로 들어갑니다.

## 2. 노션 API 토큰 발급
1. https://www.notion.com/my-integrations → **New integration**.
2. 이름(예: BAY 뉴스트래킹) + **데이터베이스가 있는 워크스페이스** 선택 → 생성.
3. **Internal Integration Secret**(토큰) 복사 → 이게 `NOTION_TOKEN`. (비밀번호처럼 취급)

## 3. 데이터베이스를 통합에 연결 (꼭 필요)
1. 그 데이터베이스를 **전체 페이지로** 엽니다.
2. 우측 상단 `⋯` → **Connections(연결)** → 만든 통합 선택.
3. 주소창의 DB ID 복사: `notion.so/`**`32자리 문자열`**`?v=...` → 이게 `NOTION_DB_ID`.

## 4. Vercel에 배포 (무료)
1. **GitHub** 가입 → New repository → `Add file` → `Upload files`
   → 이 폴더 파일들을 **구조 그대로** 업로드 → Commit.
2. **Vercel** 가입(GitHub로 로그인) → Add New → Project → 그 repo Import.
3. **Environment Variables**에 두 개 추가:
   - `NOTION_TOKEN` = (2번 토큰)
   - `NOTION_DB_ID` = (3번 DB ID)
4. **Deploy** → 공개 URL 완성.

## 5. 운영 & 인수인계
- 노션 표에 한 줄 추가 = 뉴스 1건. 수정도 노션에서 그 줄 열어 고치면 됩니다.
- 팀원에게는 노션 표 **편집 권한**만 부여.
- 인수인계: **노션 공용 계정 + Vercel(또는 GitHub) 로그인 정보**만 넘기면 끝.

## 디자인 수정
- `index.html`의 HTML/CSS만 바꾸면 됩니다(데이터 연결과 무관, 언제든 가능).
- 수정 후 GitHub에 다시 올리면 Vercel이 자동 재배포합니다.

**이미지가 안 보일 때:** 언론사 상당수(매일경제 등)는 다른 사이트에서 자기 이미지를 직접 부르는 것을
막아둡니다(핫링크 차단). 그래서 노션에서는 잘 보이던 사진이 홈페이지에서는 안 뜰 수 있습니다.
지금은 `api/img.js`가 서버에서 대신 받아와 우리 도메인으로 내보내므로 이 문제가 해결됩니다.
그래도 안 나오면 `배포주소/api/posts?debug=1` 을 열어 `대표이미지_있는_글수` 를 확인하세요.

## 문제가 생기면
- 사이트에 샘플만 보이면: 환경변수(2·3번)·통합 연결(3번)·열 이름을 확인.
- `배포주소/api/posts` 를 직접 열면 오류 메시지가 보여 원인 파악에 도움이 됩니다.
- 기사 본문(인사이트)만 안 보이면: `배포주소/api/post?pageId=페이지ID&debug=1` 로 그 글의 블록 구조를 볼 수 있습니다.
- 노션에서 고친 내용이 바로 안 보이면: 주소 뒤에 `?fresh=1` (예: `배포주소/api/posts?fresh=1`)을 붙이면 캐시를 무시하고 다시 읽습니다.
  그냥 두면 길어도 5~25분 안에 자동 반영됩니다.
